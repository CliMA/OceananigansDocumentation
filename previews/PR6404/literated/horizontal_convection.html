Horizontal convection example ​

In "horizontal convection", a non-uniform buoyancy is imposed on top of an initially resting fluid.

This example demonstrates:

  • How to use computed Fields for output.

  • How to post-process saved output using FieldTimeSeries.

Install dependencies ​

First let's make sure we have all required packages installed.

julia
using Pkg
pkg"add Oceananigans, CairoMakie"

Horizontal convection ​

We consider two-dimensional horizontal convection of an incompressible flow   on the -plane (   and   ). The flow evolves under the effect of gravity. The only forcing on the fluid comes from a prescribed, non-uniform buoyancy at the top-surface of the domain.

We start by importing Oceananigans and Printf.

julia
using Oceananigans
using Printf

The grid ​

julia
H = 1            # vertical domain extent
Lx = 2H          # horizontal domain extent
Nx, Nz = 128, 64 # horizontal, vertical resolution

grid = RectilinearGrid(size = (Nx, Nz),

                       z = (-H, 0),
                       topology = (Bounded, Flat, Bounded))

Non-dimensional control parameters and Turbulence closure ​

The problem is characterized by three non-dimensional parameters. The first is the domain's aspect ratio, and the other two are the Rayleigh () and Prandtl () numbers:

The Prandtl number expresses the ratio of momentum over heat diffusion; the Rayleigh number is a measure of the relative importance of gravity over viscosity in the momentum equation.

For a domain with a given extent, the nondimensional values of and uniquely determine the viscosity and diffusivity, i.e.,

We use isotropic viscosity and diffusivity, ν and κ, whose values are obtained from the prescribed and numbers. Here, we use   and  :

julia
Pr = 1
Ra = 1e8

ν = sqrt(Pr * b★ * Lx^3 / Ra)
κ = sqrt(b★ * Lx^3 / (Pr * Ra))

Model instantiation ​

We instantiate the model with the fifth-order WENO advection scheme, a 3rd order Runge-Kutta time-stepping scheme, and a BuoyancyTracer.

julia
model = NonhydrostaticModel(grid;
                            advection = WENO(),
                            timestepper = :RungeKutta3,
                            tracers = :b,
                            buoyancy = BuoyancyTracer(),
                            closure = ScalarDiffusivity(; ν, κ),
                            boundary_conditions = (; b=b_bcs))

Output ​

We use computed Fields to diagnose and output the total flow speed, the vorticity, , and the buoyancy, . Note that computed Fields take "AbstractOperations" on Fields as input:

julia
u, v, w = model.velocities
b = model.tracers.b

s = @at (Center, Center, Center) sqrt(u^2 + w^2)
ζ = ∂z(u) - ∂x(w)

We add to the simulation a JLD2Writer that saves the speed, the buoyancy, and the vorticity. We want to post-process buoyancy to compute the buoyancy variance dissipation (which is proportional to ). By default JLD2Writer saves the fields' halos, so when we load the buoyancy back it comes with the proper boundary conditions for computing gradients.

julia
filename = "horizontal_convection.jld2"

simulation.output_writers[:fields] = JLD2Writer(model, (; s, b, ζ),
                                                schedule = TimeInterval(0.5),
                                                filename = filename,
                                                overwrite_files = true)

Load saved output, process, visualize ​

We animate the results by loading the saved output and plotting the saved fields. From the saved buoyancy field we compute the buoyancy dissipation,  , and plot that also.

To start we load the saved fields as FieldTimeSeries.

julia
using CairoMakie

s_timeseries = FieldTimeSeries(filename, "s")
b_timeseries = FieldTimeSeries(filename, "b")
ζ_timeseries = FieldTimeSeries(filename, "ζ")

times = b_timeseries.times
Nt = length(times)

χ_timeseries = deepcopy(b_timeseries)

for n in 1:Nt
    b = b_timeseries[n]
    χ_timeseries[n] .= @at (Center, Center, Center) κ * (∂x(b)^2 + ∂z(b)^2)
end
